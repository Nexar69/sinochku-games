# v2 roadmap

## beta.1

- Modular .NET 8 Windows launcher
- Data-driven embedded game registry
- Steam-style library, search, sorting, and game detail pages
- Appearance / Updates / Steam / Games / About settings
- Steam + Steam library + CS2 detection
- SteamEdit autofix launch hook
- Stable/Beta update channels
- Logs and diagnostics
- CI build/tests and single-file Windows artifacts

- Playtime session tracking
- Recently played and favorites filters
- Release notes inside the launcher
- Theme preview without restart
- Per-game screenshots and activity feeds
- Better first-run setup wizard
- Updater rollback button and integrity hashes
- Plugin-style custom pre/post-launch hooks
- Optional Discord Rich Presence
- Additional СИНОЧКУ games
